# Data Analyst Portfolio - Sorn Tayakkanonta

**Live Demo: [https://ptsorn.github.io/sorn-simple-portfolio/](https://ptsorn.github.io/sorn-simple-portfolio/)**

A clean, modern, and responsive portfolio website showcasing my data analysis projects, technical skills, and experience.

## 🚀 Features

- **Dark/Light Theme Toggle:** Supports system preferences and manual switching with a smooth transition.
- **Modern UI/UX:** Built with a focus on readability using the "JetBrains Mono" font and a clean emerald accent color.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
- **Smooth Navigation:** Interactive navigation links and fade-in animations on scroll.
- **Project Showcase:** Highlights key data analysis projects including tech stacks and summaries.

## 🛠️ Built With

- **HTML5 & CSS3:** Custom styling with CSS Variables for theme management.
- **JavaScript (Vanilla):** For smooth scrolling, scroll animations (Intersection Observer), and theme logic.
- **Google Fonts:** Utilizing 'JetBrains Mono' for a professional, code-like aesthetic.

## 📊 Featured Projects

1. **Sales Performance Analysis**
   - *Tools:* Python, SQL, Pandas
   - Deep dive into multi-region sales data to identify growth opportunities.

2. **Customer Churn Prediction**
   - *Tools:* Scikit-learn, Matplotlib, Seaborn
   - Machine learning model to analyze and predict customer churn factors for SaaS.

3. **E-commerce Dashboard**
   - *Tools:* Tableau, Excel, SQL
   - Interactive data visualization dashboard for real-time KPIs and trends.

## 🛠️ Usage

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/PTsorn/sorn-simple-portfolio.git
   ```
2. Open `docs/index.html` in your favorite web browser.
